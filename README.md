# Bargaon Institute of Technology (BIT) Website

Official modern web portal for **Bargaon Institute of Technology (BIT)**, Bargaon, Sundargarh, Odisha.
A Unit of Sebati Devi Foundation under Badagan Institutional Group (BIG).
Approved by AICTE, New Delhi & Affiliated to SCTE&VT & BPUT, Govt. of Odisha.

## Project Structure
```
├── index.html             # Main responsive college portal
├── netlify.toml           # Netlify one-click deployment configuration
├── vercel.json            # Vercel deployment configuration
├── assets/
│   └── images/            # Logo, leadership, departments, campus photos
└── DEPLOYMENT.md          # Step-by-step deployment guide
```

## Quick Deployment Options

### 1. Netlify (Instant Drag & Drop - Free)
- Go to [app.netlify.com/drop](https://app.netlify.com/drop)
- Drag and drop this folder or `bitbargaon-website.zip`
- Your site is live instantly with an SSL certificate and custom domain support!

### 2. GitHub Pages (Free)
1. Push this code to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of BIT Bargaon website"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/bitbargaon.git
   git push -u origin main
   ```
2. Go to **Settings > Pages > Branch: main / root** and click Save.

### 3. College Hosting (cPanel / Hostinger / GoDaddy)
- Upload all files (or `bitbargaon-website.zip`) to your server's `public_html` directory via File Manager or FTP.

### 4. Vercel
- Import repository into [vercel.com](https://vercel.com) or run `npx vercel`.
